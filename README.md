# Salesforce Account Manager

## 📌 Project Overview
This project is a Salesforce-based Account Manager application designed to manage customer accounts efficiently.

## 🚀 Features
- Account creation and management
- Custom Apex logic
- Lightning Web Components (LWC) UI
- Secure data handling

## 🛠 Tech Stack
- Salesforce CRM
- Apex
- Lightning Web Components (LWC)
- SOQL
